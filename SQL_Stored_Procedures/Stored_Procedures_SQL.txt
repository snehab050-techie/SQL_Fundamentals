
SQL stored procedures
---------------------

A stored procedure is a group of SQL statements saved in the database under a name, which you can execute whenever we need it.

It's like a reusable Java method, but it is stored and executed inside the database.

Without a stored procedure
Suppose if we want to retrieve an employee's details, we have to write and execute this SQL every time.

SELECT *
FROM employees
WHERE employee_id = 101;

With a stored procedure
You save that SQL inside a procedure called GetEmployee:

CALL GetEmployee(101);

The database executes the SQL stored inside the procedure and returns the result.

----------------

Creating Procedure :

DELIMETER //

CREATE PROCEDURE GetAllEmployees()
BEGIN
	SELECT * FROM employees;
END //

DELIMETER;

------------------

Here:

DELIMITER // temporarily changes the statement terminator so MySQL can recognize the entire procedure definition.

CREATE PROCEDURE creates and saves the procedure.

GetAllEmployees() is the procedure name.

BEGIN and END enclose the SQL statements inside the procedure.

DELIMITER ; restores the normal delimiter.

----------------------

CALL GetAllEmployees();

---------------------

Stored procedure with an input parameter:

Suppose you want to retrieve employees from a particular department.

DELIMETER //

CREATE PROCEDURE GetEmployeeByDeptName(IN dept_name VARCHAR(50))
BEGIN
	SELECT *
	FROM employees
	WEHERE department = dept_name; 

END //

DELIMETER;

---------

CALL GetEmployeeByDeptName('IT');

Here, IN means the procedure receives a value from the caller. In this example, 'IT' is passed into the parameter dept_name.

Most important stored procedure questions

1. What is a stored procedure?

A reusable collection of SQL statements stored in the database and executed by calling its name.

2. What are the advantages of stored procedure?

Reusability, reduced network round trips, centralized database logic, and controlled access to data.

3. Difference between stored procedure and a function?

A procedure is called with CALL and can return result sets or output parameters. A function returns a value and can be used inside SQL expressions.

4. What are IN, OUT and INOUT parameters?

IN passes data into a procedure; OUT returns a value; INOUT accepts a value and can return an updated value.

5. How do you execute a stored procedure in SQL?

Use CALL procedure_name(arguments).

6. Can sp contain multiple SQL statements?

Yes. It can contain SELECT, INSERT, UPDATE, DELETE, and control-flow statements.

7. How to handle errors in mysql stored procedure?

Use DECLARE ... HANDLER to handle conditions such as SQL exceptions.

8. How to call a stored procedure from Java?

Use JDBC CallableStatement or Spring's JdbcTemplate / SimpleJdbcCall.

OUT parameter :

An OUT parameter lets a stored procedure return a value to the caller.

DELIMITER //

CREATE PROCEDURE GetEmployeeCount(OUT total_count INT)
BEGIN
	SELECT COUNT(*)
	INTO total_count
	FROM employees
END //

DELIMITER ;

> Call it using MySQL user-session variable

CALL GetEmployeeCount(@total);

SELECT @total;

Here, in Mysql a variable starting with @ is a user-defined session variable.

Here, @total is a variable that stores a value for your current database session.

Note: @total is not a variable declared inside the procedure. It belongs to our MySQL session, so we can access it in separate SQL statements in that same session.

--------

INOUT parameter :

An INOUT parameter allows us to:

1. Pass a value into a stored procedure.
2. Modify that value inside the procedure.
3. Return the modified value to the caller.

Think of it like a Java method that accepts a value, changes it, and returns the result.

Example: Increase a salary
Suppose we want to increase an employee's salary by ₹5,000.

Note: INOUT modifies a parameter value, while UPDATE modifies actual table data. We can use both in a procedure, depending on what we need.
------------------------

IN -> Pass a value into the procedure.

OUT -> Get a value back from the procedure.

INOUT -> Pass a value in and get an updated value back.

Conditional statements in stored procedures:


IF, ELSEIF, and ELSE

Example: Suppose we want to categorize employees based on their salary:

- Salary ≥ 70,000 --> High Salary
- Salary ≥ 50,000 --> Medium Salary
- Otherwise --> Low Salary

DELIMITER //

CREATE PROCEDURE GetSalaryCategory(
    IN emp_id INT,
    OUT salary_category VARCHAR(20)
)
BEGIN
    DECLARE emp_salary DECIMAL(10,2);

    SELECT salary
    INTO emp_salary
    FROM employees
    WHERE employee_id = emp_id;

    IF emp_salary >= 70000 THEN
        SET salary_category = 'High Salary';
    ELSEIF emp_salary >= 50000 THEN
        SET salary_category = 'Medium Salary';
    ELSE
        SET salary_category = 'Low Salary';
    END IF;
END //

DELIMITER ;

CALL GetSalaryCategory(101, @category);
SELECT @category;

-----------

Here:

IN to receive the employee ID.

DECLARE to create a local variable for the salary.

SELECT ... INTO to retrieve the salary.

IF ... ELSE to decide which message to return.

OUT to send the message back to the caller.
